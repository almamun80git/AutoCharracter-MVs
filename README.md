# AutoCharracter MV's

Static frontend by Maverick's HQ7. Black-and-white chrome, color character stills, age gate, AniList/MangaDex search, online-only chat.

## Run

Python is enough (no Node):

```
python -m http.server 8080
```

Open http://localhost:8080

ES modules and live APIs need a local server, not a raw `file://` path.
