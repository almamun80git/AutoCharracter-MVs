About

A plain-text frontend for character hunting.

AutoCharracter MV's is a static site by Maverick's HQ7. It does not train or ship an AI model. Chat calls an online HTTP API. Search calls AniList and MangaDex, then remembers queries in your browser database.

What we will not do

We will not scrape and re-host Hitomi, OmegaScans, or doujinshi galleries. Those remain source links after age confirmation. We will not serve sexual content of minors.

Stack

HTML, CSS, and native ES modules. IndexedDB for local retrieval. No build step, no Node required. Serve the folder with python -m http.server 8080 so browser modules and APIs work.
