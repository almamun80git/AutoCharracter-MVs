Features

What this frontend does.

No on-device model. No scraped mirror of Hitomi. Official JSON where it exists; outbound catalog search where CORS blocks a live feed.

  • Age gateFirst visit confirms 18+. Adult catalog links stay off until you enable NSFW on Search.
  • Live searchAniList GraphQL and MangaDex REST run in the browser. Results cache in IndexedDB.
  • CatalogsMangaBaka, Hitomi.la, OmegaScans, and Doujinshi.org open as source search pages. Those hosts do not offer a public CORS API we can legally re-host.
  • AI chatDefault path is Pollinations (open web). Optional Groq or OpenRouter if you paste a key — stored only in the request, not on our server.
  • LibraryNamed adult/SFW female characters with AniList portraits (color). UI chrome stays black and white.
  • Hall of FameFixed all-time list you specified, including Madam President (Mari Kurihara) and Rias Gremory.
